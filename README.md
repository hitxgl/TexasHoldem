# 瓦尔基里 · 德州扑克 GTO 训练竞技场

单文件 HTML 应用：绒毡牌桌对局 + GTO 启发式训练，并修正了核心牌局规则。

## 如何打开

用浏览器直接打开本目录下的 `index.html` 即可（需能访问 CDN：Tailwind、Font Awesome、Google Fonts）。

```bash
# 例如
xdg-open index.html
# 或用本地静态服务
python3 -m http.server 8080 --directory .
```

目录里正式文件只有 `index.html` 与本 `README.md`。

## 主要功能

- 5–9 人桌、可调盲注与初始筹码；两人存活时自动切到正确的单挑盲注（庄家=小盲）
- 完整翻牌前→翻牌→转牌→河牌→摊牌；烧牌；按上一次加注额计算最小加注
- 不足整加注的全押：未行动玩家可跟注/加注，已行动玩家仅可跟注差额（TDA 不重开）；边池按投入层级结算；未跟注部分退回
- 真人 + 多难度 AI；非法按钮禁用；胜者高亮与结算文案保留至下一局
- **席位动作 / 摊牌牌型更醒目**：桌上每人最近动作（弃牌/看牌/跟注/加注/全押/盲注+金额）加大字号与高对比色；摊牌时在席位下方显示中文成牌类型（如「同花」「一对A」「高牌K」），赢家额外金牌徽章
- **观战模式**：英雄出局后若桌面仍 ≥2 人，自动以 **5×** 加速继续发牌，并亮出未弃牌 AI 手牌；**弃牌观战**：英雄仍有筹码但本手已弃牌时，本手剩余流程亦 **5×**，且**英雄底牌保持正面可见**（新一局且英雄未弃牌时恢复常速），抬头提示「弃牌观战 · 五倍速」
- GTO 启发式教练与局后复盘吻合度
- **Web Audio 音效**：发牌 / 筹码 / 看牌 / 跟注 / 弃牌 / 加注 / 赢池 / 轮到你；纯振荡器+噪声，无外部音频文件；表头「音效/静音」开关（`localStorage` 记忆）；首次点击解锁 AudioContext；默认主增益与各 cue 音量已调高；出局观战 5× 时音量压低并节流，避免刷屏
- **可选升盲**：设置中开关（默认关）；按「每满一圈庄」或「每 K 手」抬盲；固定加码或倍率；表头显示当前盲注与下次升盲提示
- **手机竖屏适配**：窄屏（≤700px）改用更高牌桌比例（约 3:4）替代横屏 16:9，缩小座位/牌面/标签避免重叠；阶段提示移到桌顶；底部弃牌/跟注/加注加大可点。布局优先 `100dvh` + `visualViewport`（`--vvh`），页脚 `sticky` 并 `padding-bottom: max(12px, env(safe-area-inset-bottom) + 56px)` 清开 iOS Safari 底栏；矮屏进一步压牌桌 `max-height`，极矮屏隐藏对局日志；主区仅在必要时滚动；桌面/横屏布局保持原样

## 升盲说明

关闭时行为与原来完全一致。开启后在设置点「保存并重新开始」生效（牌局设置本身不写 `localStorage`，与人数/筹码/盲注等选项相同；仅音效开关会持久化）。

| 设置项 | 含义 |
|--------|------|
| **启用升盲** | 总开关，默认关闭 |
| **升盲间隔 · 每满一圈庄** | 当前存活人数计为「一圈」手数；打满该手数后，**下一手开始前**抬盲。庄位每手经 `getNextWithChips` 前进一人，故一圈 ≈ 存活人数手 |
| **升盲间隔 · 每固定手数** | 每隔 K 手（1–99）抬一次；与存活人数无关 |
| **升盲方式 · 固定加码** | 每次大盲 `+=` 起步大盲，小盲 = 大盲 / 2（向下取整） |
| **升盲方式 · 倍率放大** | 可选 ×1.5 / ×2 / ×2.5；大盲四舍五入，小盲 = 大盲 / 2 |

计数：`handsAtLevel` 在每手 `startHand` 发盲后自增；当 `handsAtLevel >= 间隔` 时，下一手开局先 `applyBlindRise` 再下盲。`resetTable` /「再来一局」会把盲注恢复为设置里的起步盲注并清零计数。启用时表头在盲注旁显示「N手后 → $SB/$BB」或「下局 → …」。

## 近期修复 / 改进

- 最小加注跟踪 `minRaiseSize`（不再永远 +BB）
- 短全押：迫使未对齐筹码的玩家行动；已行动者 `canRaise=false`（不可再加注）；下注轮结束需 `actedThisRound && currentBet >= highBet`
- 边池 + 未跟注退回；分池奇数筹码给**庄家左侧**最近胜者（修正原先可能落到庄家本人）
- 摊牌后 `updateUI` 不再清掉胜者高亮；结算时立即标记 `busted`
- 单挑盲注/行动顺序；出局玩家跳过；座位显示 BB 筹码
- AI/滑条/预设尊重最小加注与可加注性；行动校验防非回合点击
- `_handSeq` 取消过期定时器，避免设置重置后旧 AI 回调污染状态
- 下注预设「2倍/3倍」：无人下注时以 BB 为基数（修复原先 `currentHighBet===0` 时卡住盲注）
- 座位本街筹码更醒目（牌桌中央侧筹码堆 + 金额）；行动标签（弃牌/跟注/加注/全押等）始终显示且配色区分
- 手牌与公共牌加大，点数/花色字形更易读
- 英雄出局观战 5×：自动下一局、AI/街间延时缩短、抬头「观战 5×」徽标
- 轻量 Web Audio 音效 + 中文静音切换（持久化）；默认主增益/各 cue 音量上调
- 弃牌观战 5×：英雄仍存活但本手已弃牌时，本手剩余 AI/街进/摊牌延时按观战同倍率加速，抬头「弃牌观战 · 五倍速」；新一局英雄未弃牌即恢复常速
- **锦标赛结束 UX**：去掉阻塞式 `alert`；冠军庆祝改为**非遮挡顶栏横幅**（半透明面板 + 轻量彩纸，不盖住牌桌/手牌），含冠军文案与「再来一局」；AI 夺冠同为中性顶栏；`pointer-events` 仅面板可点，牌桌仍可见可点；调用与设置相同的 `resetTable()`；沿用 `PokerSFX.win()`
- **弃牌观战手牌**：英雄弃牌后两张底牌保持正面朝上（座位不降透明），便于 5× 观战复盘；其他玩家底牌仍背面朝上直至摊牌
- **可选升盲**：设置 UI + 手牌/一圈计数 + 加码/倍率；关闭时零行为变化
- **手机竖屏 UI**：`@media (max-width: 700px)` 调整牌桌宽高比、座位椭圆半径、控件与安全区；`resize` 时重算座位
- **iOS Safari 底栏遮挡**：页脚加大 `safe-area` + ~56px 垫高；牌桌改 `max-height`（相对 `dvh`/`--vvh`）而非强制 `min-height`；`≤640px` 高隐藏 `#game-log`；`visualViewport` 同步 `--vvh`

## 已知局限

- GTO 为教学用启发式近似，**不是**完整求解器（如 PioSOLVER）输出
- 无 Ante / 跨站多桌 / 时间银行；升盲无时间银行（仅手数/圈数）；需联网加载 CDN 资源
- 观战中「开始发牌」按钮锁定；锦标赛结束后用顶栏「再来一局」或设置重置（庆祝横幅不遮挡牌桌）；AI 仍为启发式，非真人博弈
- 浏览器可能阻止自动播放音频：需先有一次用户手势（点击）后音效才会响起
